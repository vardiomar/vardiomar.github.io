# Hexdump — Interactive terminal portfolio Jekyll theme

Hexdump is a creative Jekyll theme for developers, hackers, open-source creators, and digital minimalists who are tired of generic portfolio templates. Give your portfolio a personality with an interactive command-line experience that welcomes visitors and invites them to explore your work. This theme combines a full-featured portfolio and blog with projects, articles, testimonials, tags, newsletter support, and more, all wrapped in crisp monospace typography and a distinctive developer-focused aesthetic.

### Theme features

- Works with GitHub Pages (host it for free)
- No jQuery, only vanilla JS
- 100% responsive, mobile-optimized layout
- Interactive terminal hero with a live command prompt
- 5 built-in color themes (Matrix, Dracula, Nord, Gruvbox, Mono) with a user-facing theme switcher
- Toggleable homepage sections: hero, about, projects, posts, testimonials, subscribe
- Sidebar widgets: author, search, tags, featured posts, related posts, stats
- Social sharing buttons
- Syntax highlighting
- Copy code button
- Custom logo support
- Contact form (Formspree)
- Newsletter subscription (MailChimp)
- Disqus comments
- Google Analytics
- Font Awesome icons & free Google Fonts
- Free updates & support

### Installation

#### Installing Ruby & Jekyll

If this is your first time using Jekyll, please follow the [Jekyll docs](https://jekyllrb.com/docs/installation/) and make sure your local environment (including Ruby) is setup correctly.

* * *

### Deployment

To run the theme locally, navigate to the theme directory and run `bundle install` to install the dependencies, then run `jekyll serve` or `bundle exec jekyll serve` to start the Jekyll server.

I would recommend checking the [Deployment Methods](https://jekyllrb.com/docs/deployment-methods/) page on Jekyll website.
